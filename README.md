# SMJV

Unity Meta Quest 3 app that renders streamed MuJoCo simulations.

The companion python client: [SMJV-client](https://github.com/pzal/SMJV-client).

## First-time setup

After cloning, open the project in Unity 6.4, then:

1. **NuGet → Restore Packages**. This downloads `NetMQ`, `MessagePack`, and `websocket-sharp` DLLs.
